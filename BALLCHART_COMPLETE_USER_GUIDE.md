# BallChart Complete User Guide

This guide explains how to use BallChart end-to-end for all roles: **Admin**, **Coach**, and **Player**.

---

## 1. What BallChart Is

BallChart is a basketball academy platform that helps you:

- Manage academy teams, staff, and players
- Plan games and tactical sequences
- Assign and track player development
- Send messages and reports inside the app

---

## 2. User Roles

BallChart shows different features depending on who logs in:

- **Admin**: Full academy control
- **Coach / Head Coach / Assistant Coach**: Team operations, training, strategy, reports
- **Player**: Training progress, reports, strategy, games, messaging

---

## 3. Getting Started

## 3.1 Sign Up (Admin)

1. Open BallChart
2. Tap register/create academy account
3. Fill required fields
4. Submit registration
5. Continue from success screen

## 3.2 Login

1. Enter email and password
2. Tap Sign In
3. App automatically opens your role dashboard

## 3.3 Forgot Password

1. Tap Forgot Password
2. Enter email
3. Complete OTP/reset steps
4. Set new password

---

## 4. Navigation Basics

- Use bottom tabs to switch major modules
- Use top icons for notifications/messages/profile shortcuts
- Back behavior:
  - If not on first tab, back returns to first tab
  - On first tab, app shows **Exit App** popup

---

## 5. Admin Guide

## 5.1 Academy Dashboard

Use this as your control center for:

- academy overview
- team and staff management
- operations shortcuts

## 5.2 Create and Manage Teams

1. Open Team section
2. Tap Create Team
3. Enter team details
4. Save
5. Open team card to manage:
   - team leads
   - roster
   - team details/photo

## 5.3 Create and Manage Staff

1. Open Staff section
2. Add new staff
3. Set role and permissions
4. Save

## 5.4 Manage Players

From team detail/admin tools:

- add player
- assign to team
- edit player data

## 5.5 Profile and Security

Admin can:

- edit profile
- change password
- logout
- delete account (if enabled)

---

## 6. Coach Guide

## 6.1 Coach Home

Coach shell usually includes:

- Teams
- Games/Battle
- Strategy
- Profile

## 6.2 Teams Tab

Use it to:

- view assigned teams
- open team detail
- start training assignment flow

## 6.3 Assign Training to Players

1. Open training assignment screen
2. Select player
3. Select focus area and drill
4. Set points/date/notes
5. Assign

## 6.4 Monthly Performance Reports

1. Open Monthly Report screen
2. Select player and month
3. Open performance report editor
4. Add ratings, comments, summary, goals
5. Save report

## 6.5 Generate and Send Report PDF

After saving:

1. Tap **Send report in BallChart messages** (in-app)
2. PDF is sent to player chat
3. Use external share only when needed (WhatsApp/Email/Files)

## 8.4 Message Types

Supported:

- text

## 10. Tactical Lab Guide

## 10.1 What Tactical Lab Does

Lets coaches build and animate tactical sequences:

- drag players
- use text commands
- use voice commands
- save as strategy

## 10.2 Voice Command Use

1. Tap mic
2. First use may download local speech model
3. Speak clearly
4. Stop recording
5. App converts speech to text
6. Run command to animate

If transcription fails, app shows error hints and keeps voice clip if available.

## 13. Permissions and Requirements

## 13.1 Required Permissions

- Microphone: voice notes + tactical voice commands
- Camera/Photos: profile/team/player images

## 13.2 Internet

Most features require active internet:

- login
- messaging sync
- report save/fetch
- team/player management

## 13.3 First-Time Voice Setup

Tactical voice mode may require one-time model download before use.

---

## 14. Common Issues and Fixes

## 14.1 Can't save report

- ensure player/month selected
- check internet
- retry after a few seconds

## 14.2 Report PDF not available

- save performance report first
- then generate/send PDF

## 14.3 Voice command not working

- enable microphone permission
- wait for model download
- speak clearly and closer to mic

## 14.4 Message not sent

- check internet
- reopen conversation
- retry send

---

## 15. Best Practices

- Keep team data (players, staff, leads) up to date
- Save reports before trying to publish PDFs
- Use in-app report send for official player communication
- Use tactical lab text fallback when voice is unclear
